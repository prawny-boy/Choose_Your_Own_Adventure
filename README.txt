This is a python game, developed by Oliver Liu, Sean Chan and Levi Laij.
Version 2.4 Beta

SETUP:
1. Open your terminal prompt and type these and enter:
    MAC: "pip3 install termcolor", "pip3 install keyboard", "pip3 install threading"
    WINDOWS: "pip install termcolor", "pip install keyboard", "pip install threading"
2. Download python 3.12 or higher from your browser, search "download python" and click the first link. Install IDLE also.
3. Watch this video on youtube and follow it: https://youtu.be/kYlHPEqLzto
Important: Make sure to open the whole folder if you are using VS Code.
If you are using MAC, use Python IDLE or VS code to run it.

WARNING:
If you are using D: drive, this program will break unless you rename the folder CYOA.py is in to "CYOA Beta"
