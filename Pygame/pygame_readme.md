### Information and usage
This is made by Aaron. Please do not modify any of this without permission.
Modifying this might cause problems, inconsistencies and bad code.

Conventions:
- Use snake case
- Use rectangles if you can
- Use sprite classes if you can
- Add comments
- Make variables clear
- Organise variables and make sub-variables
- Write docstrings after completing a function
- Follow pygame conventions, (which include but are not limited to) performance and using an event loop
